KEY TOPICS COVERED
═══════════════════════════════════════════════════════════════════════════════════

FOUNDATIONAL CONCEPTS:
✓ CSV format (delimited, variable-length fields)
✓ XML format (hierarchical, nested elements)
✓ When to use each format
✓ Strengths and limitations of each

XML SPECIFICS:
✓ Elements and their anatomy (opening tag, content, closing tag)
✓ PCDATA (Plain Character Data) - text inside elements
✓ Attributes (key-value pairs in tags)
✓ Content particles (Sequence, Choice, All)
✓ Complex types (contains child elements)
✓ Simple types (contains only PCDATA)
✓ XML declaration and root element requirement

MAP DESIGN:
✓ INPUT structure for CSV (repeating records, variable fields)
✓ OUTPUT structure for XML (nested elements, PCDATA)
✓ Cardinality notation (M/C, min-max)
✓ Record and field creation
✓ Field property configuration

MAPPING LOGIC:
✓ 1:1 field-to-element mapping
✓ Loop handling for repeating records
✓ How each CSV row becomes an XML DATA element
✓ Advanced transformations (concatenation, lookups, conditions)

EXECUTION FLOW:
✓ Saving .mxl source file
✓ Compiling to .txo binary
✓ Deploying to Sterling server
✓ Map Test dialog usage
✓ Server-side processing
✓ HTTP request/response flow

VALIDATION & RESULTS:
✓ Expected XML output structure
✓ Validation report interpretation
✓ Error and warning messages
✓ Troubleshooting common issues
✓ Performance considerations

FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════════════

Q: How long should I spend on this training?
A: Minimum 1.5 hours (presentation + exercises). Full deep-dive: 3-4 hours.

Q: Can I modify the presentation for my company?
A: Yes! PPTX is fully editable. Update colors, logos, examples as needed.

Q: Do I need IBM Sterling installed to use this training?
A: Not necessary. Training explains concepts. To actually build maps, you need
   access to Sterling Map Editor.

Q: What if I have 1000 CSV rows?
A: The map automatically handles it. Loop repeats 1000 times (up to max 9999).

Q: How do I add complex transformations?
A: Foundation covered in Slide 7 and Module 4. Advanced transformations require
   extended rules and custom logic (beyond scope of this training).

Q: Can I use this training for EDI formats?
A: Yes! EDI formats are similar (delimited input, hierarchical output).
   Concepts apply directly to EDI mapping.
